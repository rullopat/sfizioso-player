# Simple Sine

Open `instrument.sfz` in a Player build with manifest support. The minimal
`instrument.json` adds the instrument and preset names. The Player supplies its
default theme and generic Volume/Vibrato knobs from SFZ labels; there is no
artwork or authored presentation. The built-in oscillator needs no samples.

Edit the JSON name and save to see the automatic reload. Remove `instrument.json`
to try plain SFZ loading: the same labelled controls and sound remain available.
