# Sfizioso Player 1.0.0-rc.1

First release candidate for Sfizioso Player 1.0.0. This is a prerelease for
compatibility testing, not the stable 1.0 release.

## Changes since 0.12.3

- Optional `instrument.json` presentation for loose SFZs and plaintext bundles:
  instrument/preset names, grouped CC controls, knobs, sliders, toggles, accent
  colours, and bounded PNG/JPEG artwork.
- Reusable BSD components for manifest parsing, presentation snapshots, artwork
  preparation, bridge data, and React rendering. Sample Machine and commercial
  consumers can integrate these without importing the Player application.
  JUCE and other dependencies retain their own licences.
- JUCE 9.0.2, including the matching WebView frontend and Linux dependencies.
- Removed inactive oversampling controls and their Player wiring, the
  Experimental tab, unused coming-soon panels, and the unused VirtualFs stub.
- The MPE editor now offers only Off and Full. Old Pressure values continue to
  behave as Off; Full keeps its original saved and automation value. A deprecated
  C++ alias and legacy parameter slot remain solely for compatibility.
- Expanded authoring documentation, playable examples, screenshots, and native
  and browser regression coverage.

The bundled audio engine remains sfizioso 1.2.2.

## Compatibility and RC testing

- The retired oversampling host parameter is no longer exposed. Loading an older
  serialized state containing it is covered by a regression test. Remaining
  parameter IDs are unchanged, but parameter-list indices have changed: check
  existing DAW automation assignments before relying on this candidate.
- Native plugin/bundle version fields report `1.0.0` because they require numeric
  versions; the Player UI and GitHub release identify `1.0.0-rc.1`. The plugin
  identifiers remain unchanged, so installing this candidate replaces the
  previous Player in hosts. Keep the 0.12.3 installer/archive for rollback.
- Test scanning and loading, MIDI and MPE playback, multiple plugin instances,
  automation, offline rendering, save/close/reopen, and instrument reload in your
  usual DAW. Compare existing projects with 0.12.3.
- The manifest v1 contract is a release candidate. Sample Machine export,
  branded-product integration, and a generic preset browser remain follow-ups.
- macOS artifacts are not notarized.

## Downloads

- macOS: Standalone, AU, and VST3.
- Windows: Standalone and VST3.
- Linux: Standalone and VST3.

Platform archives and `SHA256SUMS` accompany the GitHub prerelease. Verify an
archive with `sha256sum --check SHA256SUMS` (Linux) or
`shasum -a 256 --check SHA256SUMS` (macOS) after downloading all listed archives.

Report issues with the OS, DAW/version, plugin format, reproduction steps, and
whether the same project works with 0.12.3. Use a copy of the project for testing.
